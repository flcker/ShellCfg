# 计划：跨平台多编辑器 LSP 安装与配置管理

## Context

当前仓库 (`~/.config/zsh`) 完全没有 LSP 基础设施：nvim 只有 treesitter 语法高亮，Zed 依赖自动检测，`init.sh` 不安装任何 LSP 服务器。用户需要一套统一的 LSP 管理方案，覆盖 macOS/Linux/Windows 三平台、VSCode/Zed/nvim 三编辑器以及 Claude Code/opencode 等 AI 编程工具。

目标语言：TypeScript/JavaScript、Python、Rust、C/C++、Go、Lua（nvim 配置语言）。

---

## LSP 安装位置

**策略：由系统包管理器统一安装到系统级 PATH，所有编辑器/工具共用同一份二进制。**

| 包管理器 | 安装目录 |
|---|---|
| brew (macOS) | `/opt/homebrew/bin/` |
| apt (Linux) | `/usr/bin/` |
| npm global | `$(npm prefix -g)/bin/` |
| cargo | `~/.cargo/bin/` |
| go install | `~/go/bin/` |
| winget (Windows) | 系统 PATH |

特殊：`clangd` 随 `brew install llvm` 安装但不自动 link，`lsp_install.sh` 在安装后创建 symlink `/opt/homebrew/bin/clangd → $(brew --prefix llvm)/bin/clangd`。

mason.nvim 额外在 `~/.local/share/nvim/mason/bin/` 管理一份，仅用于 nvim fallback，不影响系统 PATH。

### 1. `README.md`

内容结构：
- **概述**：说明本仓库用途（跨平台 LSP 管理，数据源 `lsp_config.json`）
- **支持的 LSP 服务器**：表格列出语言、server 名称、命令、安装方式
- **快速开始**：macOS/Linux 和 Windows 的安装+配置命令
- **脚本说明**：`lsp_install` 和 `lsp_configure` 分别的职责和用法
- **编辑器集成**：各编辑器（nvim/Zed/VSCode/AI 工具）如何使用这些 LSP
- **扩展 lsp_config.json**：如何添加新语言的说明

### 3. `lsp_install.sh`（仅负责安装）

```bash
#!/usr/bin/env bash
# 职责：读取 lsp_config.json，将 LSP 服务器安装到系统 PATH
# 用法：bash lsp_install.sh
```

逻辑：
1. 内联 python3 解析 lsp_config.json
2. 检测平台（`uname -s`）和可用包管理器
3. 每个 server：`command -v <command>` 已存在则 `✓` 跳过
4. 否则按 priority 顺序找第一个可用的包管理器安装（`→`）
5. 无可用安装器则 `✗` 提示
6. 安装后执行 `post_install`（如 clangd symlink）
7. 打印摘要

### 4. `lsp_install.ps1`（Windows 安装）

```powershell
# 职责：同 lsp_install.sh，PowerShell 7 实现
# 用法：pwsh lsp_install.ps1
param()
```

逻辑同 sh，使用 `ConvertFrom-Json`，检测 winget/scoop/npm/cargo/go。

### 5. `lsp_configure.sh`（仅负责编辑器配置）

```bash
#!/usr/bin/env bash
# 职责：读取 lsp_config.json，应用 Zed 和 VSCode 编辑器配置
# 用法：bash lsp_configure.sh [zed|vscode|all]
```

**`apply_zed` 函数**：
- 动态检测 `which clangd` 获取实际路径（兼容不同平台/安装方式）
- 用 python3 将 `"lsp"` 字段合并进 `~/.config/zed/settings.json`（先备份）
- 写入的内容：clangd 显式 binary 路径

**`apply_vscode` 函数**：
- 检测 `code` 命令可用
- 遍历 `vscode_extensions` 数组，执行 `code --install-extension <ext> --force`
- 打印每个扩展的安装状态

### 6. `lsp_configure.ps1`（Windows 编辑器配置）

同结构，PowerShell 7 实现：
- `Apply-Zed` / `Apply-Vscode` 函数
- VSCode 路径：`$env:APPDATA\Code\User\settings.json`

### 8. `submodule/nvim/lua/lsp.lua`（新建）

**确保 LSP 存在**的两层机制：
1. mason `automatic_installation = true`：nvim 首次启动时自动安装 `ensure_installed` 中缺失的 server
2. `vim.fn.executable(cmd[1])` 运行时检查：lspconfig 只 setup 可执行的 server，避免报错

```lua
require("mason").setup()
require("mason-lspconfig").setup({
  ensure_installed = { "tsserver","pyright","rust_analyzer","clangd","gopls","lua_ls" },
  automatic_installation = true,
})

local lspconfig = require("lspconfig")
local caps = require("cmp_nvim_lsp").default_capabilities()

local on_attach = function(_, bufnr)
  local map = function(k, f) vim.keymap.set("n", k, f, { buffer = bufnr }) end
  map("gd",          vim.lsp.buf.definition)
  map("K",           vim.lsp.buf.hover)
  map("<leader>ca",  vim.lsp.buf.code_action)
  map("<leader>rn",  vim.lsp.buf.rename)
  map("gr",          vim.lsp.buf.references)
end

for _, srv in ipairs({ "tsserver","pyright","rust_analyzer","clangd","gopls","lua_ls" }) do
  local cmd = lspconfig[srv].document_config.default_config.cmd
  if cmd and vim.fn.executable(cmd[1]) == 1 then
    lspconfig[srv].setup({ on_attach = on_attach, capabilities = caps })
  end
end
```

nvim-cmp sources 追加（在现有 `plugins.lua` 的 cmp.setup 中）：
```lua
{ name = "nvim_lsp" }
```

## 执行顺序

1. 在 ShellCfgSubmodule 远端创建 `lsp` 分支
2. 主仓库 `git submodule add` 注册 `submodule/lsp`
3. `submodule/lsp/` 中创建 5 个文件（README + json + 4 个脚本），commit/push 到 lsp 分支
4. `submodule/nvim/` 中修改 plugins.lua、新建 lsp.lua，commit/push 到 nvim 分支
5. 主仓库 `git add submodule/lsp submodule/nvim`，commit

## 验证方式

| 步骤 | 命令 | 预期结果 |
|---|---|---|
| 安装 LSP | `bash submodule/lsp/lsp_install.sh` | 所有 server ✓/→ |
| PATH 验证 | `which typescript-language-server pyright rust-analyzer clangd gopls lua-language-server` | 全部有输出 |
| Zed 配置 | `bash submodule/lsp/lsp_configure.sh zed` | `~/.config/zed/settings.json` 含 `"lsp"` 字段 |
| VSCode 扩展 | `bash submodule/lsp/lsp_configure.sh vscode` | `code --list-extensions` 包含所有条目 |
| nvim Mason | nvim 中 `:Mason` | 显示已安装 servers |
| nvim LSP | 打开 `.ts` 文件，`:LspInfo` | tsserver attached |
| nvim 容错 | server 未安装时启动 nvim | 不报错，跳过未安装的 server |
